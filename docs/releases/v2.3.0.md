# Snap & Trade v2.3.0

Screenshot workflow refined from reported NDX/CAC 40 failure cases:

- Available-evidence scoring with visible denominator and unavailable criteria.
- Required execution + higher-timeframe context; missing context means abstain.
- Latest-price axis label preferred over cursor OHLC and quote panels.
- Structural stop plus 1.5 × mean closed-candle range; `--avg-candle` validation.
- Opening-plan mode and explicit cancellation bounds via `--open-price`.
- Short trade card by default, detailed explanation on request.
- Long/short entry and exit analysis; short plan sizing requires explicit config.
- Existing sell-side simulation verified; signed short debt and collateral checks.
- Broker helper explicitly blocks short-entry execution (long-only fill tracker); no trading permissions enabled.
- Synthetic visual fixtures, archival-answer evaluator, reproducible skill ZIP,
  checksums, illustrative GIF and clean-directory CLI installation smoke test.

Includes v2.2 input validation, cost-aware sizing and journal integrity fixes.
Source and module attribution retained. No measured image accuracy or trading
profitability claimed. The synthetic fixtures/animation are development aids,
not real chart evaluations or a recorded model session. Real screenshot,
hosted-client and paper-provider validation remain outstanding.

Download snap-and-trade.zip, compare its SHA-256 checksum and import its skill
folder. Requires Python 3.10+. Default paper/no-short/no-margin remains.
